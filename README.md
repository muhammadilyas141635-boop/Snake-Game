# Snake Game

## Project Description
This is a classic Snake Game developed using C# and Windows Forms in Visual Studio 2022.

The player controls a snake using keyboard keys and collects food to increase the score and grow the snake.

## Features
- Keyboard controls (Arrow Keys and W, A, S, D).
- Three difficulty levels: Easy, Medium, and Hard.
- Score tracking system.
- Small Food (10 Points).
- Large Food (20 Points).
- Snake growth after collecting food.
- Border collision detection.
- Self-collision detection.
- Pause and Resume functionality.
- Restart Game option.
- Exit Game option.

## Technologies Used
- C#
- Windows Forms (.NET Framework)
- Visual Studio 2022
- Object-Oriented Programming (OOP)

## How to Play
1. Click the START button to begin the game.
2. Use Arrow Keys or W, A, S, D to move the snake.
3. Collect food to increase your score.
4. Press P or click PAUSE to pause the game.
5. Click STOP to restart the game.
6. Avoid hitting the game borders or the snake's own body.
